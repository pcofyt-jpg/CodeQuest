# Найденные ошибки (проверка сайта после «Ночной миссии»)

Список ведётся по сообщениям владельца проекта. Пока только записываем; исправления — после разбора всего списка.

| № | Где | Что не так | Заметка разработчика | Статус |
|---|---|---|---|---|
| 1 | «Старт: с азов», урок 1 «Как устроен сайт» → карточка «HTML, CSS, JavaScript» (блок «Новое в этом уроке» и шпаргалка) | В примере кода строка `button.addEventListener(…)` неполная: нет `id` у кнопки и нет `document.querySelector`. Если ребёнок скопирует пример кнопкой «Скопировать», код не заработает | Пример должен быть рабочим целиком: кнопке дать `id`, в CSS обращаться по нему, в JavaScript найти кнопку через `querySelector` и написать полный обработчик. Стрелки-подписи «← HTML» вынести из кода, иначе скопированный текст тоже сломается. Проверить остальные карточки шпаргалки: пример с многоточием «…» должен быть явно помечен как «часть кода», а не выдаваться за готовый | Записано |
