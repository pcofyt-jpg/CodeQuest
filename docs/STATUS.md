# CodeQuest — текущее состояние (для продолжения работы в новом чате)

Обновлено: 3 ноября 2026. Последний коммит — см. `git log -1`.

## Продукт
Учебная студия для детей 9–12 лет (Россия): сайты на HTML/CSS/JavaScript и программы на Python в браузере.
Сайт: https://pcofyt-jpg.github.io/CodeQuest/ · Репозиторий: pcofyt-jpg/CodeQuest · Папка владельца: `D:\Codequest\V4\codequest`.
Обновления передаются файлом `.bundle`: `git pull "ПУТЬ\К\файл.bundle" main` → `git push` → GitHub Actions выкладывает сайт.

## Стек
Next.js 16 (статический экспорт для GitHub Pages), React 19, TypeScript, Tailwind 4, CodeMirror 6, Vitest, Playwright (e2e на Python).
Python в браузере — Pyodide 314 в фоновом потоке (ADR 0003). ИИ-наставник — YandexGPT Pro через функцию Yandex Cloud (ADR 0002).
Песочница предпросмотра: iframe без allow-same-origin + CSP (ADR 0001).

## Маршрут — 98 уроков (шаги на карте миссий)
1 «Старт: с азов» (4) → 2 Курс 1 «Первый сайт» (11) → 3 Практикум «Понимаю структуру кода» (8) → 4 Задачник 1 (6)
→ 5 Курс 2 «Настоящий сайт» (12) → 6 Задачник 2 (6) → 7 «Сверстай по образцу» (6) → 8 Курс 3 «Мини-игры» (13)
→ 9 Курс 4 «Профессиональная вёрстка» (12). Параллельно: «Python: первые шаги» (10) → «Кибердетектив» (10).
Содержание: `src/content/lessons/*.ts`, эталоны — `references.json`, шпаргалка — `src/content/glossary.ts`.

## Возможности студии
Урок «Понять → Попробуй → Сделай → Проверь себя»; программные проверки (DOM, код, сценарии игр, Python-вывод, робот,
контраст WCAG, структура); подсказки (убывают); шпаргалка с выбором карточки по языку; помощник по структуре HTML/CSS
(строка + причина); подсветка пары тега; «Студия проверит:»; «Разбор решения» (3 неудачи + все подсказки);
«Разминка дня» (повторение пройденного); контрольная миссия курса → сертификат в стиле игры («LEVEL UP!», навыки-значки, профиль игрока с Кью, медаль с результатом контрольной; печать на альбомный A4); входная проверка (8/10 → «Старт»
и курс 1 засчитаны, без сертификата); «Мои проекты» и шаблоны; библиотека картинок; резервная копия в файл.
На телефоне: вкладки «Задание / Код / Результат» и «Проверить» в нижней панели; над кодом — свёрнутое задание
(шаги и «Студия проверит»); с открытой клавиатурой шапка и вкладки прячутся, над клавиатурой — строка символов
под язык файла (`< > { } ( ) ; = "` и др., отступ, отмена); после проверки панель прокручивается к итогу.
Дизайн «Ночная миссия» (тёмная тема, курсы — планеты, робот Кью). Варианты ответов показываются перемешанными.

## Проверки качества
`npm run check` — типы, линтер, 189 модульных тестов (уроки Python прогоняются в настоящем Pyodide; помощник
по структуре — ноль ложных подсказок на эталонах). e2e: `e2e/test_all_lessons.py` (все 98 уроков, 524 проверки) и
тематические наборы (mobile, python, structure, daily_sample, review_control, practice_extras, projects_backup, images,
lesson_flow, preview_security).

## Открытые задачи и идеи (подробно — docs/CURRICULUM.md, docs/AI-REVIEW.md)

- Не делаем по решению владельца: озвучка объяснений.
