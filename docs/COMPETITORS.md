# Конкуренты: что берём и чем отличаемся

Источники — открытые страницы площадок (октябрь 2026). Сайт kodysha.ru изучить не удалось:
владельцы запретили автоматический доступ, а в поисковой выдаче площадки нет.

## Кодик (itcodik.com, приложение «Кодик: Python, HTML, C++, JS»)

Широкая аудитория (курсы, «профессии», подготовка к работе), не детская платформа.
Приложение: оценка 4,7 в Google Play, 100 тыс.+ скачиваний.

**Как начинается маршрут.** Курс HTML — 8 модулей, 53 урока, 530+ заданий. Первый модуль —
«Введение в HTML»: что такое HTML, структура документа, теги и атрибуты, вложенные теги.
Писать заголовки начинают только во втором модуле. Обучение по схеме «Понять → Попробовать → Применить»,
внутри уроков много коротких заданий разных форматов: разобрать код, найти ошибку,
проследить выполнение, собрать решение. Модули заканчиваются тестом и практикой («Исправляем навигацию»).

**Что ещё есть:** ИИ-ассистент «Кодик GPT»; шаблоны проектов (мем-генератор, игра на память);
открытая лента проектов; ежедневные задачи, соревнования и лидерборд; клуб (сообщество);
сертификаты — только с подпиской PRO; менторство «Кодик Max» с ответом за 3 рабочих дня;
выбор персонажа-маскота.

**Из отзывов:** «очень затягивает»; просят копировать учебный материал в конспект;
недовольны, что сертификаты доступны только по подписке.

## Что мы взяли и как сделали лучше для детей 9–12 лет

| У Кодика | У нас |
|---|---|
| Модуль «Введение» перед кодом | Курс «Старт: с азов» — 4 урока, **плюс урок про раскладку клавиатуры**: как печатать < > { } # (для детей это главный барьер, взрослые платформы его не замечают) |
| Много коротких заданий | Разминка «Попробуй» в каждом уроке «Старта» и курса 1: выбери ответ, собери код из строчек, вставь пропущенное, напечатай. Подсказка «включена русская раскладка» |
| Понять → Попробовать → Применить | Понять → Попробуй → Сделай → Проверь себя, этапы видны вверху урока |
| Сертификат по подписке | **Бесплатный** сертификат за курс, с понятным списком навыков; имя хранится только в браузере |
| Шаблоны проектов | Шаблоны «Открытка», «Викторина», «Кликер» |
| Нельзя копировать материал | Кнопка «Скопировать» у примеров в шпаргалке |
| ИИ-ассистент | ИИ-наставник, который учит, а не решает; скобки проверяет программа, урок засчитывают только проверки |
| Ментор отвечает за 3 рабочих дня | Наставник отвечает за 1–3 секунды |

## Что сознательно не берём

- **Открытая лента проектов и лидерборды** — публичные детские страницы и соревнования рискованны;
  вместо ленты — «Скачать сайт» и в будущем закрытая ссылка «Покажи семье».
- **Механики давления** (жизни, штрафы за пропуски) — учимся ради результата, а не ради серии.
- **Платный сертификат** — сертификат бесплатный, это наше преимущество в отзывах родителей.

## Что ещё стоит сделать (по убыванию пользы)

1. Курс 3 «Мини-игры» — то, за чем дети идут на игровые площадки, но на настоящем JavaScript.
2. Отчёт для родителя: что пройдено, чему научился, где застрял.
3. Режимы наставника «Помоги начать» и «Свободный вопрос».
4. Разминки «Попробуй» для курса 2.
5. Маскот-персонаж для наставника.
6. Модульные мини-тесты в конце курса (у нас пока тесты после каждого урока).

## CodeCombat, Ozaria, AI League (экосистема CodeCombat)

**CodeCombat** — игра, в которой настоящий код (Python по умолчанию, JavaScript) управляет героем:
первые уровни — только движение (`hero.moveRight()`), потом число шагов, потом новые команды. Ошибка видна
как событие в игре. Есть уровни-практика для тех, кто застрял, и «комбо-испытания» после нескольких тем.
Слабые места: не работает на телефонах и планшетах; премиум-подписка с ограниченными ИИ-подсказками.

**Ozaria** — сюжетная программа для школ: понятия вводятся через сценки и диалоги персонажей, в конце главы —
творческий итоговый проект. Только для классов (нет домашней версии); в сюжете нет выбора.

**AI League** — соревнования, где игроки программируют поведение своих команд ИИ.

### Что мы взяли

| У них | У нас |
|---|---|
| Код управляет героем (`hero.moveRight()`) | Робот Кью: `robot.right()`, `robot.up(2)`, стены, кристаллы, флажок; путь анимируется |
| Сначала движение, потом число шагов, потом новое | Урок 1 — шаги, урок 2 — повороты и число шагов, урок 3 — цикл `for` вместо повторов |
| Сюжет и диалоги (Ozaria) | Реплика робота Кью в начале каждого урока Python |
| Итоговый проект главы (Ozaria) | Урок 8 — игра «Угадай число», которую можно показать друзьям |
| Python в браузере | Настоящий CPython (Pyodide), а не упрощённый интерпретатор |
| Только компьютер (CodeCombat) | Работает и на телефоне |

### Что не берём (пока)

- **Соревнования AI League** — для детей 9–12 сравнение с чужими результатами и общение с незнакомыми
  игроками рискованно. Возможная альтернатива позже: «арена» против встроенных ботов, без рейтинга незнакомцев.
- **Боевой сеттинг CodeCombat** — у нас робот-курьер и кристаллы вместо огров.
