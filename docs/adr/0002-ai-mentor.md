# ADR 0002. ИИ-наставник: провайдер и архитектура

Статус: принято, реализованы режимы 1–2 (25.10.2026). Модель (Lite или Pro) выбирается по результатам eval.mjs.

## Проверенные условия (по официальным источникам, октябрь 2026)

- **Anthropic (Claude)**: Россия не входит в поддерживаемые регионы; неподдерживаемым считается и использование
  из такого региона. Посредники-«шлюзы» отвергнуты: нарушение условий провайдера и неизвестная судьба данных детей.
- **YandexGPT (Yandex AI Studio)**: API для бизнеса, есть OpenAI-совместимый API; инфраструктура в РФ
  (152-ФЗ, по заявлению Yandex Cloud); логирование запросов отключается заголовком `x-data-logging-enabled: false`.
  Цена (по вторичным источникам, совпадающим между собой; сверить с официальной страницей при подключении):
  YandexGPT Lite ≈ 0,20 ₽ / 1000 токенов, YandexGPT Pro 5.1 ≈ 0,80 ₽ / 1000 токенов (синхронно).
- **GigaChat (Сбер)**: с 1 сентября 2026 новые клиенты оплачивают модели через cloud.ru; для API нужны сертификаты
  НУЦ Минцифры; бесплатный режим для физлиц рассчитан на личное использование.

## Решение (предложение)

1. **Провайдер для пилота — YandexGPT** через OpenAI-совместимый API. Код обращается к модели через интерфейс
   `AIProvider`, поэтому замена провайдера — одна новая реализация, без изменений в студии.
   Lite или Pro — выбрать по тестовому набору из ошибок наших уроков (качество объяснений для детей).
2. **Ключ — только на сервере.** GitHub Pages не может хранить секреты, поэтому нужен небольшой серверный
   посредник в РФ — функция Yandex Cloud Functions: проверяет доступ и лимиты, собирает запрос, вызывает модель
   с отключённым логированием, проверяет формат ответа.
3. **Доступ на пилоте — по коду доступа**, который родитель вводит один раз. Без кода наставник выключен.
   Лимиты: на код в день, на размер запроса, на длину ответа; оповещение о бюджете в Yandex Cloud.
4. **Минимум данных.** Отправляются только файлы урока, текст ошибки и номер урока. Никаких имён и аккаунтов.
   Сервер не сохраняет тексты запросов, журналирует только количество и размер.
5. **Педагогика.** Наставник отвечает по-русски, коротко, сначала наводящим вопросом и объяснением; готовый код —
   только как предложение, которое ребёнок видит и сам применяет или отклоняет. За ребёнка задание не решает
   и проверку урока не засчитывает.

## Режимы по очереди

1. «Объясни ошибку» — кнопка рядом с ошибкой в консоли.
2. «Что не так?» — при непройденной проверке, с учётом результатов проверок.
3. «Помоги начать» — для финальных проектов и свободного режима.
4. Свободный вопрос — позже, после модерации входа и выхода.

## Реализация

- `functions/ai-mentor/index.js` — функция; тесты `index.test.mjs` (модель подменена заглушкой).
- Браузер отправляет «простой» запрос (`text/plain`), поэтому предварительный CORS-запрос не нужен;
  функция всё равно корректно отвечает на OPTIONS только для своих адресов.
- Лимит вопросов в день считается в памяти экземпляра функции — приблизительно; жёсткую границу задаёт бюджет.
- В студии наставник скрыт, если при сборке не задан `NEXT_PUBLIC_AI_MENTOR_URL`.
- `e2e/test_mentor_ui.py` проверяет интерфейс против имитации функции.
