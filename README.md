# CodeQuest (рабочее название)

Учебная веб-студия, в которой дети 9–12 лет создают сайты и мини-игры на HTML, CSS и JavaScript.

**Курс 3 «Интерактив и мини-игры»** (12 уроков): кликер, «Угадай число», викторина, «Камень, ножницы, бумага»,
«Бегун», тренировка и своя игра. Проверки-сценарии играют в игру ребёнка сами.

**Состояние: этапы 1–4 (демо).** Вводный курс «Старт: с азов» (4 урока: как устроен сайт, клавиатура
программиста, теги и вложенность, как устроена студия) и два курса, всего 26 уроков. Уроки идут по схеме
«Понять → Попробуй → Сделай → Проверь себя», с короткими заданиями-разминками. Бесплатный сертификат за курс,
шаблоны в «Моих проектах». Сравнение с конкурентами — docs/COMPETITORS.md.

**Дизайн «Ночная миссия»** (выбран из трёх вариантов): тёмная тема, курсы — миссии на карте, мятный акцент,
янтарный — текущий урок; шрифты Unbounded, Rubik, JetBrains Mono (хранятся на сайте). Цвета — токены
в src/app/globals.css; макеты вариантов — артефакт «CodeQuest — варианты дизайна».

**Python.** Раздел «Python: первые шаги» (8 уроков, открыт сразу): робот Кью на поле (как в CodeCombat),
print, переменные, input, if/else, игра «Угадай число» с while. Настоящий Python (Pyodide) в фоновом потоке:
вечный цикл останавливается, сеть закрыта. Решение и ограничения — docs/adr/0003-python.md.
Файлы Python копируются в public/pyodide автоматически перед `npm run dev` и `npm run build`. Курс 1 «Первый сайт» (10 уроков): свой сайт на любую
тему через 8 уроков проекта и 2 тренировки. Курс 2 «Настоящий сайт» (12 уроков): сайт об увлечении — каркас,
списки, меню, картинки из безопасной библиотеки, отступы, рамки, ряды на flexbox, версия для телефона;
финал — сайт с чистого листа по чек-листу. Работают редактор, изолированный предпросмотр,
консоль с понятными объяснениями ошибок, программная проверка с подсказкой «что сделать» к каждой
непройденной проверке, шпаргалка с примерами, контрольная точка, короткий тест после урока,
«Мои проекты» (свободный режим), «Скачать сайт» одним HTML-файлом, перенос прогресса через файл,
подсказки при опечатках в названиях команд, ИИ-наставник (YandexGPT через функцию в Yandex Cloud,
по коду доступа: «Объясни ошибку» и «Что не так?»).
Прогресс хранится только в браузере. Аккаунтов, сервера с данными, ИИ и платежей пока нет — намеренно.

## Запуск

Нужен Node.js 20.9 или новее (рекомендуется 22, см. `.nvmrc`).

```bash
npm install       # ставит точные версии из package-lock.json
npm run dev       # режим разработки: http://localhost:3000
```

Production-сборка:

```bash
npm run build
npm start
```


## Как устроены уроки

- **Урок проекта** (`track: "project"`) продолжает код ребёнка из прошлого урока проекта и дописывает
  в конец файлов заготовку (`additions`). Если код сломался, кнопка «Взять рабочую версию прошлого урока»
  подставляет эталон прошлого урока с заготовкой этого.
- **Тренировка** (`track: "practice"`) работает на своём коде и не меняет сайт ребёнка.
- Проверки описываются данными (`Check` в `types.ts`): `message` — что проверяем, `fix` — что сделать,
  если не получилось.
- `newTerms` — понятия урока из `glossary.ts`. Они показываются карточками в уроке и пополняют шпаргалку.
- `quiz` — 2–3 вопроса после урока. Переход дальше они не блокируют.

После изменений запустите `npm test`. Тесты каталога проверяют: у каждой проверки есть подсказка,
ответы тестов корректны, понятия есть в шпаргалке, эталон проходит проверки кода, а стартовый код — нет.
Затем `python e2e/test_all_lessons.py` проходит все уроки подряд в браузере.

## Важно о безопасности

Код ребёнка никогда не выполняется в контексте приложения. Почему выбраны именно эти меры
и чего ещё не хватает до публичного запуска — в `docs/adr/0001-preview-isolation.md`.
