# CodeQuest (рабочее название)

Учебная веб-студия, в которой дети 9–12 лет создают сайты и мини-игры на HTML, CSS и JavaScript.

**Состояние: этап 1–2 (демо).** Работают маршрут из 10 уроков, редактор, изолированный предпросмотр,
консоль с понятными объяснениями ошибок, подсказки и программная проверка заданий. Прогресс хранится
только в браузере. Аккаунтов, сервера с данными, ИИ и платежей пока нет — это сделано намеренно.

## Запуск

Нужен Node.js 20.9 или новее (рекомендуется 22, см. `.nvmrc`).

```bash
npm install       # ставит точные версии из package-lock.json
npm run dev       # режим разработки: http://localhost:3000
```

Production-сборка:

```bash
npm run build
npm start
```

## Проверки

```bash
npm run check      # типы + линтер + модульные тесты
npm run typecheck  # только TypeScript
npm run lint       # только ESLint
npm test           # только Vitest
```

Сквозные тесты в настоящем браузере лежат в `e2e/` (см. `e2e/README.md`).

## Структура

```
src/
  app/                       маршруты Next.js (главная, /learn/[slug])
  components/
    RouteMap.tsx             главная: маршрут уроков
    studio/                  студия: редактор, предпросмотр, консоль, урок
  content/lessons/
    types.ts                 формат урока и проверок
    catalog.ts               10 уроков MVP
  lib/
    preview/                 изоляция и сборка предпросмотра, защита циклов
    checks/                  проверки исходного кода
    progress/                прогресс и черновики (пока в браузере)
docs/
  ARCHITECTURE.md            архитектура MVP и план этапов
  RISKS.md                   риски и вопросы к юристам и специалистам
  adr/                       записанные архитектурные решения
e2e/                         сквозные тесты (Python + Playwright)
```

## Как добавить урок

Добавьте объект в `src/content/lessons/catalog.ts`. Проверки описываются данными
(см. `Check` в `types.ts`), а не функциями: так их можно безопасно выполнить в песочнице
и позже повторить на сервере. После изменения запустите `npm test` — тесты каталога
проверят, что стартовый код разбирается, регулярные выражения корректны,
а подсказок не становится больше от урока к уроку.

## Важно о безопасности

Код ребёнка никогда не выполняется в контексте приложения. Почему выбраны именно эти меры
и чего ещё не хватает до публичного запуска — в `docs/adr/0001-preview-isolation.md`.
