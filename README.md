# CodeQuest (рабочее название)

Учебная веб-студия, в которой дети 9–12 лет создают сайты и мини-игры на HTML, CSS и JavaScript.

**Состояние: этапы 1–3 (демо), учебная программа v2.** Ребёнок строит один сайт на свою тему
через 8 уроков проекта и 2 тренировки на чужом коде. Работают редактор, изолированный предпросмотр,
консоль с понятными объяснениями ошибок, программная проверка с подсказкой «что сделать» к каждой
непройденной проверке, шпаргалка с примерами, контрольная точка, короткий тест после урока.
Прогресс хранится только в браузере. Аккаунтов, сервера с данными, ИИ и платежей пока нет — намеренно.

## Запуск

Нужен Node.js 20.9 или новее (рекомендуется 22, см. `.nvmrc`).

```bash
npm install       # ставит точные версии из package-lock.json
npm run dev       # режим разработки: http://localhost:3000
```

Production-сборка:

```bash
npm run build
npm start
```

## Проверки

```bash
npm run check      # типы + линтер + модульные тесты
npm run typecheck  # только TypeScript
npm run lint       # только ESLint
npm test           # только Vitest
```

Сквозные тесты в настоящем браузере лежат в `e2e/` (см. `e2e/README.md`).

## Как устроены уроки

- **Урок проекта** (`track: "project"`) продолжает код ребёнка из прошлого урока проекта и дописывает
  в конец файлов заготовку (`additions`). Если код сломался, кнопка «Взять рабочую версию прошлого урока»
  подставляет эталон прошлого урока с заготовкой этого.
- **Тренировка** (`track: "practice"`) работает на своём коде и не меняет сайт ребёнка.
- Проверки описываются данными (`Check` в `types.ts`): `message` — что проверяем, `fix` — что сделать,
  если не получилось.
- `newTerms` — понятия урока из `glossary.ts`. Они показываются карточками в уроке и пополняют шпаргалку.
- `quiz` — 2–3 вопроса после урока. Переход дальше они не блокируют.

После изменений запустите `npm test`. Тесты каталога проверяют: у каждой проверки есть подсказка,
ответы тестов корректны, понятия есть в шпаргалке, эталон проходит проверки кода, а стартовый код — нет.
Затем `python e2e/test_all_lessons.py` проходит все уроки подряд в браузере.

## Важно о безопасности

Код ребёнка никогда не выполняется в контексте приложения. Почему выбраны именно эти меры
и чего ещё не хватает до публичного запуска — в `docs/adr/0001-preview-isolation.md`.
